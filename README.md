# Приложение для записи к косметологу — шаблон

Демо: https://vladislav-sites.github.io/kosmetolog-demo/ (мастер и данные вымышленные; кабинет — ссылка «Кабинет мастера», PIN 0000).
Сайт пересобирается автоматически после каждого пуша в `main` (GitHub Actions → Pages).

Сайт-приложение (PWA): клиентка открывает ссылку, может «добавить на экран» и записаться в пару касаний.
У мастера — кабинет с расписанием, ценами и графиком.

## Как сделать версию под нового мастера

Поменять **только** `src/config/master.ts`: имя, адрес, контакты, стартовые процедуры, график, образование, тему.
Дальше процедуры, разделы и цены мастер ведёт сама в кабинете — вкладка «Процедуры».
Для своего фото: положить файл в `public/` и указать `portrait: "./foto.jpg"` (у процедур — `photo`).
Иконку и название на экране телефона поменять в `public/manifest.webmanifest`, `public/icon-*.png` и `index.html`.

## Что внутри

- Клиентская часть: главная, процедуры (описание, подготовка, противопоказания),
  запись (процедура → дата → время → контакты + согласие на ПД), подтверждение + файл для календаря,
  «Обо мне», подарочные сертификаты, политика конфиденциальности (шаблон).
- Кабинет `#/admin` (демо-PIN 0000): записи по дням (подтвердить / пришла / отменить, закрыть день),
  «Позвать снова» — кому пора на повтор, с готовым сообщением в WhatsApp, график, оформление.
- Кабинет → «Сертификаты»: заявки с сайта и три номинала, которые мастер меняет сама (любая сумма от 100 до 1 000 000 ₽).
- Кабинет → «Процедуры»: добавить новую, изменить всё (название, раздел, цена, «от», длительность, описание,
  этапы, подготовка, противопоказания, курс, «позвать снова через N дней»), скрыть, удалить, поменять порядок;
  создать, переименовать и удалить пустой раздел; отметить, какая процедура — консультация.
- Четыре оформления: «Аметист» (тёмно-фиолетовое, по умолчанию), «Молочное», «Олива», «Ночь».
- Эффект Liquid Glass на «парящих» элементах: нижнее меню-«пилюля», шапки, плашка «Ближайшее окно», панель записи, уведомления.

## Ограничения демо

Данные хранятся в браузере (localStorage), поэтому запись видна в кабинете только на том же устройстве.
Для настоящего мастера нужен сервер с базой в РФ (152-ФЗ) и уведомления мастеру в Telegram —
слой данных в `src/lib/store.ts` для этого и выделен.

## Запуск

Нужен Node.js 22+.

```bash
npm install
npm run dev
```

Сборка для хостинга: `npm run build` → папка `dist/` (статические файлы, подходит любой хостинг).
